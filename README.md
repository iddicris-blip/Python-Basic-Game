# Python-Basic-Game

Basic python game where you guess the correct number.

## Description

A simple number guessing game built in Python. The player attempts to guess a randomly selected number within a specified range.

## Features

- Random number generation
- User input validation
- Feedback on guesses (too high, too low, or correct)
- Game loop with replay option

## Getting Started

### Prerequisites

- Python 3.x

### Running the Game

```bash
python main.py
```

## How to Play

1. Run the game
2. The game will think of a random number
3. Make your guess
4. Follow the feedback to adjust your next guess
5. Try to guess the number correctly!
